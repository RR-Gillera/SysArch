# PHP — CCS Sit-in Monitoring System

This folder contains the full PHP equivalent of the `SignUpLogin` ASP.NET Core MVC project.

## Requirements

| Tool | Version |
|------|---------|
| PHP  | 8.1 or later |
| MySQL / MariaDB | 5.7 / 10.4 or later |
| Web Server | Apache (mod_rewrite) or Nginx |

PHP extensions required: `pdo`, `pdo_mysql`, `fileinfo`.

---

## Quick-start (XAMPP / WAMP / Laragon)

1. **Place the project** in your web root so it is accessible at `http://localhost/php/`.  
   Example for XAMPP: copy the `php/` folder into `htdocs/`.

2. **Create the database** in MySQL:
   ```sql
   CREATE DATABASE SignUpLoginDB CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. **Configure the connection** in `config.php`:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'SignUpLoginDB');
   define('DB_USER', 'root');
   define('DB_PASS', '');          // change to your MySQL password
   ```

4. **Create the tables** by visiting:
   ```
   http://localhost/php/setup.php
   ```

5. **Open the app**:
   ```
   http://localhost/php/login.php
   ```

## Creating an admin account

Run this SQL (replace the password hash with one generated by `password_hash('yourpassword', PASSWORD_BCRYPT)`) or use the PHP snippet below:

```php
<?php
echo password_hash('Admin@123', PASSWORD_BCRYPT);
```

Then insert:
```sql
INSERT INTO signups
  (IdNumber, FirstName, LastName, MiddleName, CourseLevel, Course, Address, Email, Password, Role, RemainingSessions, CreatedAt)
VALUES
  ('admin', 'CCS', 'Admin', '', 'N/A', 'N/A', 'N/A', 'admin@ccs.edu', '<HASH_HERE>', 'Admin', 0, NOW());
```

Log in using **ID Number**: `admin` (or the `FirstName` of the admin) and the password you hashed.

## Notes

* Passwords are hashed with PHP's built-in `password_hash(PASSWORD_BCRYPT)`, which is wire-compatible with BCrypt.Net used in the original C# project.  
* CSRF tokens protect every state-changing form and POST action.  
* All user input is sanitised via `htmlspecialchars()` (the `e()` helper) before output.  
* The `images/profiles/` directory must be **writable** by the web server (`chmod 755` or `777` on Linux).
